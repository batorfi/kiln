# Changelog

## 0.2.0 — 2026-10-25 — teal and sand, three faces, the first real files
- **What.** Palette changes from warm neutrals with an ember accent to *teal and sand* (accent `#0F766E`, page `#F4F1EA`, ink `#14201F`, deep-teal rail). Type changes from one system sans to three faces: Charter (display), Inter (interface), monospace. Status colours retuned for contrast; `danger` added. Dark mode defined. Tokens, contrast registry, 12 components, 5 patterns and foundations written as files.
- **Why.** Teal is calm and does not compete with amber *waiting*, the one colour a person must notice without alarm; the ember stays the brand mark's colour. Charter gives each screen's one sentence a human voice.
- **Decided by.** human@batorfi, 2026-10-25 (theme direction approved in conversation).
- **Breaking.** Every colour value changes; token ids that named the ember (`color.ember.*`) are replaced by `color.teal.*`. No product code exists yet.
