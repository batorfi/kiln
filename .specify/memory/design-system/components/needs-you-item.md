# needs-you-item

## Purpose
One thing waiting on a person: blocking, suggestion or worth knowing.

## Anatomy
kind · headline · evidence · waited · what it blocks · Open

## Variants
blocking · suggestion · worth-knowing

## States
default · hover · focus · done (leaves the list)

## Accessibility
list item with a heading; the count in the rail is a live region announced politely.

## Content
Headline says what is needed in a sentence.

## Behaviour
Never expires, never reorders itself; order is suggested and stated.

## Do and don't
Do: show what it blocks. Don't: use urgency colours.

## Used in
S2 · rail count
