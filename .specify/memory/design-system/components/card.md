# card

## Purpose
A bounded surface for a group of related content.

## Anatomy
container · optional heading · body

## Variants
default · raised · selected

## States
focusable only when it contains one primary action

## Accessibility
a region labelled by its heading when it is a landmark-level group.

## Content
—

## Behaviour
Not clickable as a whole unless it is a single link.

## Do and don't
Do: border not shadow. Don't: nest more than two levels.

## Used in
most screens
