# empty-state

## Purpose
What a list says when it is empty.

## Anatomy
sentence · optional one action

## Variants
first-use · nothing-waiting · error

## States
static

## Accessibility
a heading and text; the action is a real button.

## Content
Say what is true: *Nothing is waiting on you.* Never a blank screen.

## Behaviour
—

## Do and don't
Do: reassure when empty is good news. Don't: invent urgency.
