# feed-item

## Purpose
One thing the person fed KILN, with KILN's drafted destinations.

## Anatomy
kind icon · gist · source and time · state pill · proposals (→) · Open

## Variants
waiting · kept · done

## States
default · hover · focus

## Accessibility
proposals are text chips with `→` and are not controls in the list; a full list item with one Open link.

## Content
Proposals read *→ Knowledge page*; never *Recommended*.

## Behaviour
Opening goes to the item page; deciding happens there.

## Do and don't
Do: show the original untouched. Don't: pre-select a destination.

## Used in
S19 Feed · the item page
