# Typography

Three faces, each with one job.

- **Display — Charter** (fallbacks Bitstream Charter, Iowan Old Style, Georgia): page headings only — the one plain sentence each screen says. Bold, 28 px (36 px on the first-run welcome).
- **Interface — Inter**: everything people read and click. 13–16 px body, 14 px default; tabular figures for counts, times and money; weights 400, 500, 600.
- **Monospace**: ids (`S6.R9`, `X3`), paths, hashes, commands. Never for sentences.
- Line height 1.45 for body, 1.25 for headings. Measure: 60–75 characters for reading text.
- Sizes are tokens and scale with the user's browser or OS setting; layouts never fix text heights.
