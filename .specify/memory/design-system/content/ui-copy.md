# Interface copy

Voice: the charter's — direct, plain, second person; sentence headings that say what is true; no exclamation marks; no metaphors from the kiln analogy.

## Glossary (the same word on web, terminal and editor)
| Use | Not |
|---|---|
| Factory, Feature, Step | project, ticket, task |
| Knowledge | wiki |
| Needs you | inbox, notifications |
| Gate brief | review page |
| Feed | dump, inbox |
| Waiting for you | pending, blocked |
| Architecture (the gate) | Design (the gate) |

## Rules
- Buttons: verb first, no punctuation.
- Counts and times carry units (*2 h*, *41 of 64 GB*).
- Errors: what happened, what it means, what to do.
- Say what is true when empty or waiting; never create urgency.
- Strings are localisable; nothing is baked into images.
