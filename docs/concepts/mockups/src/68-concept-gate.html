The work

What is proposed?
Problem. Every step in kiln-v1 runs on one model. Nothing stops a judge from running on a weaker model than the author it judges, and roles exist only as code paths, not as definitions a person can read and change.
Proposal. Define each role as an agent file, and bind roles to models through one tier map — with judges always on the strongest model.
