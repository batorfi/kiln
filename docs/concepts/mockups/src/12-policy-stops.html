When policy stops the factory, it asks — it never works around

Three kinds of stop that are not gates. Each pauses only what it must, explains which rule fired, and offers choices that are recorded as yours.

Blocked by policykiln-v1 · yesterday 22:47

A research step tried to send source code to a cloud model

The researcher wanted to ask claude-opus-5-5 about Pi's durable API and attached src/lane.ts (6 KB). The request was stopped before it left — nothing was sent.
Rule: profile local-only — no model or tool may reach beyond this machine.
Step now: continued without the answer; flagged “source unavailable” in its output.

Keep it blocked

Nothing changes. The flag stays visible at the next gate as missing evidence.

Change the factory's profile…

Opens kiln-v1's models & policy. A profile change is a recorded decision and applies from the next step — never to this one.

There is no “allow just this once” in a local-only factory: the profile is the promise.
