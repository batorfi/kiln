keep_alive asks Ollama to keep a model loaded, but Ollama can still evict it under memory pressure (Model eviction mid-judgment). Residency is guaranteed only when KILN pins the model in its pool (Model pool, Judge hold).

Note — this is why the lane refuses to unload a held judge's model; see r10 · Role agents and model tiers.
