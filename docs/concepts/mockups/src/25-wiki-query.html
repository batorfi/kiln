You: If the lane refuses to unload a held judge's model, what happens when memory runs out?asked 10:01
Answer

From 5 pages · wiki keeper · 41 s · local

all claims cited

The work that needs memory waits; nothing is evicted and nothing fails. A held judge's model stays loaded until its verdict Judge hold, and the model pool will not grant a lease that exceeds the memory budget — the requesting step stays queued Model pool.

Ollama on its own would not guarantee this: keep_alive is a request, and the server can evict under memory pressure Ollama. That is exactly what happened on Oct 14 Model eviction mid-judgment new today.

So the change r10 is making — the lane itself refusing to unload a held judge's model — closes the gap the incident exposed, provided the pool also pins the model Single lane.

Not in the wiki: how long a queued step may wait before the health watcher reports it. The schema has no page for it.
