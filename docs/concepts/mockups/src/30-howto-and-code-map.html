Add a role to the tier map

how-toin progress · 3 of 4 steps proven · waits for Verificationcode at 7c2e9a1
Use this when the factory needs a new kind of agent — for example a security reviewer. Roles are declared once and bound to a model in one place; judges can only bind to the strongest model.
1

Write the role's agent definition

Create agents/security-reviewer.md with its instructions and whether it is a line-of-defense role.

--- role: security-reviewer lineOfDefense: true ---
✓ proven by roles.test.ts › every role has an agent definition
2

Bind it in the tier map

Add one line in src/tiers.ts. A judge bound to anything but the strongest model fails closed with TierPolicyError — see Why judges fail closed.

bindRole(roles.securityReviewer, strongest());
✓ proven by tiers.test.ts › judges bind only to the strongest model
3

Never name the model anywhere else

Model names live only in the tier map; the reviewer's finding 2 removed the last hard-coded names from roles.ts and walk.ts.

✓ proven by tiers.test.ts › no model names outside the tier map
4

Check the role runs on a live model

Run the live tier with a local model loaded; the new judge should hold the lane through its verdict.

◷ waits for Verification — the live tests are running now
