Team space

a git repository, not a server — coordinates workshops, decides no one's gates

  • team roadmap by quorum
  • claims on paths · overlap
  • requests & mirrored reviews
  • team knowledge · team rules (floor)
  • signed acts · members' keys
cross-cutting

Configuration as code

kiln.config/ — hosts, providers, models, roles, tiers, gates, flows, policies, health

  • checked before applied (all or nothing)
  • applies from the next step
  • team → workshop → factory: only stricter

Policy & egress

  • profiles: local-only · hybrid · cloud
  • checked before every outbound request
  • everything that left is recorded
  • budgets pause, never skip

Security & identity

  • loopback bind · per-launch secret · Host/Origin checks
  • personal signing keys · host identities
  • secrets only in the OS store

Observability

  • everything built from the record
  • metrics · traces · insights · health
  • opt-in OTLP export to loopback
